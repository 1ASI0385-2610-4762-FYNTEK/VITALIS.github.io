##  3. Core Features & Historias de Usuario (Sprint 1)

El ecosistema de VITALIS unifica herramientas de productividad y salud mental en una interfaz responsiva asíncrona, cumpliendo estrictamente los requerimientos validados en el Product Backlog:

* **HU-01: Registro de Estado Emocional Diario (`Mood Tracking`):** Permite registrar el ánimo con un solo clic utilizando una escala simplificada de glifos monocromáticos para evaluar variaciones en la bitácora transitoria.
* **HU-02: Evolución de Niveles de Estrés (`Historial de Presión`):** Renderiza un gráfico de barras interactivo semanal que muestra de forma limpia los picos de fatiga y cansancio reportados por el usuario.
* **HU-14: Registro de Tareas Pendientes (`Checklist Diario`):** Caja de tareas interactiva y libre de sobreestimulación cromática que permite tachar y atenuar dinámicamente las responsabilidades completadas.
* **HU-31: Asistente de Hábitos Personalizados con IA:** Panel adaptativo que inyecta sugerencias proactivas automatizadas basadas en el rol seleccionado (por ejemplo, pausas ergonómicas para mitigar el sedentarismo en la oficina).
* **HU-11 / HU-13: Planificador de Bloques de Estudio:** Calendario integrado de línea de tiempo por bloques fijos que unifica las horas de clase de la UPC, jornadas de oficina y descansos guiados en una sola vista coordinada.

##  4. Capas del Código Fuente & Arquitectura de Software

El proyecto web está desarrollado de manera limpia empleando tecnologías nativas del lado del cliente, garantizando tiempos de carga ultrarrápidos gracias al descarte de recursos gráficos pesados:

* **Estructura Semántica (`HTML5`):** Segmentada en módulos independientes reutilizables (`<header>`, `<main>`, `<section>`, `<footer>`) estructurando los formularios de acceso, módulos interactivos de tareas y la pasarela de planes.
* **Presentación Visual Zen (`CSS3`):** Basada estrictamente en el uso intensivo de espacios en blanco (`White Space`) y una paleta monocromática estricta (`#FFFFFF`, `#030213`, `#ECECF0`) acoplada a un sistema de espaciado proporcional en múltiplos de `8px`.
* **Comportamiento Dinámico (`Vanilla JavaScript`):** Controla las micro-interacciones de la plataforma, como el efecto expansivo radial (`zen-ripple`) al accionar botones, la inyección y guardado local de datos (`sessionStorage`), la modificación interactiva del gráfico de barras de estrés y las cuentas regresivas.
